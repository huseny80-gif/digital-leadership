# صوتيات ملخصات المحاضرات

تعرض `summaries.html` ملخصات محاضرات الابتكار وإدارة المشاريع الخمس المنشورة. لكل محاضرة ستة تسجيلات مستقلة مرتبطة بنصها الأصلي، مع نسخ فصيحة وعراقية وسعودية. لا يُستخدم تسجيل محاضرة أخرى أو التسجيل التجريبي السابق بدلًا من أي مسار.

## تنظيم الملفات

المجلدات `innovation-01` إلى `innovation-05` تحافظ على ترقيم المحاضرات المعروض في صفحة الملخصات. داخل كل مجلد:

- `summary.txt`: النص الأكاديمي الأصلي المعروض في الصفحة، لم يُغيَّر أثناء إنتاج الصوت.
- `msa.txt`: النص الفصيح الجاهز للنطق، مع تهجئة المصطلحات اللاتينية صوتيًا وقراءة الأرقام والرموز بالكلمات.
- `iraqi.txt` و`saudi.txt`: صياغتان شفويتان للهجتين العراقية والسعودية؛ ليستا مجرد تغيير صوت يقرأ النص الفصيح. تحافظان على ترتيب الفقرات والمفاهيم والأمثلة والأرقام والمعنى، ويستخدم الصوتان من الجنسين النص نفسه لكل لهجة.
- `msa-male.mp3` و`msa-female.mp3`، و`iraqi-male.mp3` و`iraqi-female.mp3`، و`saudi-male.mp3` و`saudi-female.mp3`: ملفات التسجيل الفعلية.

مثال: `assets/audio/innovation-02/iraqi-female.mp3`. أُبقيت هذه الأسماء القائمة حتى تستدعيها القائمة المنسدلة دون تغيير الروابط المحجوزة. لا توجد ملفات صامتة أو فارغة، ولا يُستخدم `speechSynthesis` أو تحويل اللهجة داخل المتصفح.

## الإفصاح عن الجودة والأصوات

هذه تسجيلات مولّدة بالذكاء الاصطناعي وليست أصوات أشخاص سجلوا المحتوى في استوديو. وافق المستخدم على مزوّد عصبي بديل بدل ElevenLabs. استُخدمت مكتبة `edge-tts==7.3.1` بسرعة قراءة −5%، والأصوات التالية بحسب فهرس المزوّد:

- الفصحى الرجالية: `ar-SY-LaithNeural`، والفصحى النسائية: `ar-SY-AmanyNeural`؛ يقرأ الصوتان النص الفصيح، وهما صوتان إقليميان سوريان وليسا أصواتًا محايدة معتمدة بشهادة لغوية.
- العراقية الرجالية: `ar-IQ-BasselNeural`، والعراقية النسائية: `ar-IQ-RanaNeural`.
- السعودية الرجالية: `ar-SA-HamedNeural`، والسعودية النسائية: `ar-SA-ZariyahNeural`.

صيغة المصدر مضغوطة MP3، بمعدل 24 كيلوهرتز وقناة واحدة؛ يُسجل معدل الترميز الفعلي لكل ملف في `manifest.json` ولا يُفترض من اسم الجودة. يُفك المصدر إلى WAV وسيط للمعالجة ثم يصدر MP3 بمعدل 160 كيلوبت/ثانية عند معدل العينة الأصلي. لا يستعيد رفع معدل الترميز تفاصيل لم تكن موجودة في المصدر، ولا تُضاف قنوات ستيريو أو عينات أعلى لإيهام المستخدم بجودة جديدة.

تُسوّى الجهارة بمستهدف −16 LUFS وذروة حقيقية مستهدفة −1.5 dBTP قبل الضغط. تُقاس الجهارة والذروة بعد الترميز، ويُرفض الناتج إذا تجاوز هامش الذروة −1 dBTP أو خرج عن نطاق الجهارة المقبول. يُفحص فك الملف كاملًا. المراجعة النصية للصياغات والتفريغ الآلي لا يشكلان شهادة استماع بشري أو ضمانًا لنطق لهجي مثالي؛ تبقى مراجعة متحدثين أصليين مفيدة للضبط النهائي.

خلال فحص هذه الدفعة رُفض ملف عراقي رجالي تجاوز الذروة، وأُصلح من مصدره المحفوظ بهامش −2.5 dBTP. كذلك كشف التفريغ الآلي نقص خاتمة النسخة السعودية الرجالية للمحاضرة الخامسة؛ أُعيد إنتاج هذا الملف وحده في فقرات قصيرة بالنص الكامل، ثم اجتاز فحص البداية والخاتمة والمحتوى. لم تُستبدل الملفات الأخرى أو تتغير النصوص بسبب الإصلاح.

## الفهرس والتحقق

يحافظ `manifest.json` على `sourceSha256` و`summarySha256` و`summaryRevision` الأصلية. لكل تسجيل فعلي تُحفظ بصمة نصه المقروء `transcriptSha256`، ومساره `transcript`، وبصمة MP3 `sha256`، وحجمه `bytes`، ومدته، وصوت المزوّد، ومقاييس الجهارة، وبصمة ملخص المصدر `sourceSummarySha256`.

لا تُفعَّل `available: true` قبل نجاح إنتاج الملفات الثلاثين والفحص. يعرض رابط نص التسجيل في المشغّل النص المختار للفصحى أو اللهجة، بينما يبقى الملخص الأكاديمي المعروض كما هو. تقارن المزامنة البصمات والمسارات وتمنع ربط صوت قديم بملخص أو نص متغير.

## إعادة الإنتاج

من جذر المستودع، أنشئ بيئة Python اختيارية خارج الملفات المنشورة، وثبّت اعتماديات أداة الصوت:

```sh
python3 -m venv /absolute/path/audio-venv
/absolute/path/audio-venv/bin/python -m pip install -r scripts/requirements-exam-audio.txt
/absolute/path/audio-venv/bin/python scripts/produce-lecture-audio.py --work /absolute/path/private-production-work --concurrency 2 --skip-enable
```

تتطلب الأدوات FFmpeg وFFprobe واتصالًا بخدمة النطق. الإنتاج محدود التوازي ويستأنف التسجيلات السابقة التي تطابق النص والصوت والبصمة بدل توليدها مجددًا. تُحفظ ملفات المصدر والقياسات وإيصالات الإنتاج في مجلد العمل الخاص، لا في المستودع ولا في صفحة عامة. توجد إعادة محاولة واحدة فقط لطلب المزوّد الفاشل؛ لا تعاد الملفات السليمة بسبب تعثر النشر.

بعد مراجعة المحتوى الفعلي، شغّل الأمر نفسه دون `--skip-enable` لتفعيل الفهرس من الإيصالات السليمة، ثم:

```sh
node scripts/sync-exam-audio.mjs
node scripts/sync-exam-audio.mjs --check
node --test scripts/sync-exam-audio.test.mjs
python3 scripts/produce-lecture-audio.test.py
```

تُنشر نسخ مطابقة تحت `web/public/assets/audio/` لتعمل على Next.js، وتبقى المسارات نسبية لاستضافة الملفات الثابتة. لا تُرسل تفضيلات الاستماع إلى الخادم، ويتوقف التسجيل السابق عند تبديل الصوت، ولا يبدأ التشغيل تلقائيًا. هذه أدوات تحديث صريحة؛ لا توجد خدمة توليد دورية أو عملية مراقبة دائمة.
