# صوتيات ملخصات المحاضرات

تعرض `summaries.html` ملخصات محاضرات الابتكار وإدارة المشاريع الخمس المنشورة
والمعتمدة. لكل محاضرة مشغل مستقل وستة مسارات MP3؛ لا توجد تسجيلات لهذه
المحاضرات في هذا المجلد حتى الآن. لا تُنشئ ملفات فارغة أو صامتة بدلًا منها.

| المجلد | المحاضرة |
| --- | --- |
| `innovation-01` | الأولى |
| `innovation-02` | الثانية |
| `innovation-03` | الثالثة |
| `innovation-04` | الرابعة |
| `innovation-05` | الخامسة |

يحتوي كل مجلد على `summary.txt`، وهو النص الأكاديمي المعروض في بطاقة
المحاضرة نفسها. لا يتضمن النص أسئلة الاختبار أو ملحقاته. لكل مجلد الأسماء
المحجوزة التالية:

| اسم MP3 | الصوت واللهجة |
| --- | --- |
| `msa-male.mp3` | العربية الفصحى — رجالي |
| `msa-female.mp3` | العربية الفصحى — نسائي |
| `iraqi-male.mp3` | العراقية — رجالي |
| `iraqi-female.mp3` | العراقية — نسائي |
| `saudi-male.mp3` | السعودية — رجالي |
| `saudi-female.mp3` | السعودية — نسائي |

مثال: `assets/audio/innovation-02/iraqi-female.mp3` يخص ملخص المحاضرة الثانية
بصوت نسائي عراقي فقط. لا تستخدم تسجيل المحاضرة الأولى أو تسجيل القيادة
الرقمية التجريبي بدلًا منه. اختيارات القائمة مسارات لتسجيلات فعلية، وليست
توليدًا صوتيًا أو تحويلًا للهجة داخل المتصفح. لا يُستخدم `speechSynthesis`.

## إضافة تسجيل فعلي

1. سجل النص `summary.txt` الخاص بالمحاضرة، أو أنتج تسجيلًا مرخصًا له. راجع
   التسجيل بالاستماع للتأكد من مطابقة المحتوى، وضبط النطق، والصوت واللهجة
   المحددين. بيانات الملف وبصمته لا تثبت هذه المطابقة وحدها.
2. ضع MP3 سليمًا بالاسم المحدد في مجلد المحاضرة. لا تضف أسرار مزود صوت أو
   تسجيلات تحتوي على بيانات شخصية. هذه المسارات عامة عند النشر.
3. غيّر `available` إلى `true` لذلك الصوت فقط داخل `manifest.json`. لا تغير
   `path` أو بصمات المصدر والنص؛ لا تربط صوتًا قديمًا بنص تغير محتواه.
4. نفذ من جذر المستودع:

   ```sh
   node scripts/sync-exam-audio.mjs
   node scripts/sync-exam-audio.mjs --check
   node --test scripts/sync-exam-audio.test.mjs
   ```

5. اختبر التشغيل، التبديل، والتحميل على `summaries.html`، ثم أضف الأصل
   ونسخته المطابقة تحت `web/public/assets/audio/` إلى Git وانشر التحديث.

يبقى الخيار غير المتوفر ظاهرًا، وتوضح الواجهة عدم نشر تسجيله دون طلب ملف
مفقود. أي خطأ في الاتصال أو فك الصوت يعطّل التحميل والتحريك مع إتاحة إعادة
المحاولة. لا يُشغّل الصوت تلقائيًا، ويتوقف التسجيل السابق عند تبديل الصوت.

`manifest.json` يربط كل محاضرة ببصمة ملفها الأصلي (`sourceSha256`) وبصمة
UTF-8 للنص المقروء (`summarySha256`) وبنسخة مجموعة الملخصات
(`summaryRevision`). عند تعديل ملخص معتمد، حدّث النص المعروض و`summary.txt`
وبصمتهما والنسخة في الصفحة والبيان معًا، وأعد كل تسجيل قديم إلى
`available: false` حتى إعادة تسجيله ومراجعته. تفحص المزامنة تطابق النص
والبصمات والمسارات وتمنع اعتماد ملف مفقود أو ملف لا يحمل ترويسة MP3.

المسارات نسبية لتعمل على GitHub Pages وNext.js. يحفظ المتصفح اختيار الصوت
والسرعة لكل محاضرة محليًا؛ لا ترفع الصفحة نصًا أو ملفًا إلى أي خدمة صوت.
