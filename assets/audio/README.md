# صوتيات ملخصات المواد الدراسية

هذه حزمة تسجيلات محفوظة للمواد الخمس: الذكاء الاصطناعي وتحليل البيانات، وحوكمة الأمن السيبراني، والابتكار وإدارة المشاريع، والثقافة القانونية والتنظيمية، وإدارة المخاطر. تشمل الدفعة التاريخية 26 ملخصًا وستة مسارات صوتية محتملة لكل ملخص؛ وهي ليست فهرس المحاضرات الحالي في المنصة. حالة كل تسجيل محفوظ وبصمته تظهر في `manifest.json`؛ وجود المسار وحده لا يعني إتاحة الملف. تُحفظ تسجيلات الابتكار الثلاثون السابقة دون إعادة توليد إذا بقيت المصادر والبصمات مطابقة.

المصدر هو `backend/content/finquiz/catalog.json` للمحاضرات المنشورة و`academicSummaries.json` للملخصات المعتمدة، مع معرّفات المواد UUID في `backend/src/finquiz/catalog.ts`. لا يُضاف سجل محاضرة قديم غير منشور لمجرد وجوده في أرشيف الملخصات. تُغطى خارطة ISO 27001 المنشورة بدل السجل القديم `cs-l6` غير الموجود في قائمة المحاضرات الحالية.

## التنظيم والنصوص

توجد الملفات في `assets/audio/<lecture-id>/`. بقيت مسارات `innovation-01` إلى `innovation-05` السابقة كما هي؛ وتستخدم المواد الأخرى معرّفات الكتالوج مثل `ai-l1` و`cs-iso-roadmap` و`lg-l3` و`rm-l1`. رقم معرّف الكتالوج ليس بالضرورة ترتيب المحاضرة؛ رقمها المعروض ومادتها محددان في الفهرس وبيانات الصفحة.

يحتوي `summary.txt` على النص الأكاديمي الأصلي المعروض، فيما تحتوي `msa.txt` و`iraqi.txt` و`saudi.txt` على النصوص الفعلية الجاهزة للنطق. تُحفظ المفاهيم والأقسام والأمثلة والأرقام والشروط، وتُقرأ المصطلحات والأرقام بالكلمات عند الحاجة. الصياغة اللهجية ليست منهجًا جديدًا أو ترخيصًا لتغيير معنى النص، خصوصًا الشروط القانونية والمعايير. مراجعات الصياغة والتفريغ آلية، وليست مراجعة بشرية أو اعتمادًا جديدًا للمصدر.

تحتوي `study-data.json` على بيانات دفعة التسجيلات المحفوظة فقط، ولا تُضمَّن في واجهة الملخصات. تعرض كل مادة ملخصاتها الحالية عبر `/subjects/<UUID>/summaries` داخل المنصة وبصلاحيات المتدرب المعتادة. تُقرأ المحاضرات المنشورة وملفاتها المعتمدة من واجهة المادة، ثم تُعرض نقاط الملخص الأكاديمي وشرحها؛ وتشمل إدارة المخاطر المحاضرات الست. لا توجد قائمة تجمع ملخصات المواد في الصفحة نفسها. يفتح الرابط القديم `/summaries.html?subject=<UUID>` صفحة المادة المقصودة، والرابط العام يقود إلى المواد الدراسية. يُحلّ معرّف المحاضرة القديم وفق الكتالوج الحالي، حتى إن تغيّر ترتيبها.

يرتبط مشغّل كل محاضرة بمعرّف مادتها ومحاضرتها وبصمة نص ملخصها والصوت المختار. يُجهز MP3 عند طلب التشغيل باستخدام خدمة النطق الموجودة في الخادم، مع حالة انتظار قابلة للإلغاء وإعادة المحاولة. لا يُعرض تسجيل قديم عند تغيّر الملخص، ولا يُستبدل تسجيل محاضرة بأخرى. يتطلب هذا المسار اتصال خدمة النطق الخارجية؛ فشلها يظهر للمستخدم دون الادعاء بجاهزية التسجيل. تبقى الملخصات والبودكاست منفصلة عن الاختبار الشامل الموجود في «المادة الامتحانية».

## الأصوات والجودة

المزوّد البديل `edge-tts 7.3.1`. الأصوات الثابتة: الفصحى الرجالية `ar-SY-LaithNeural` والنسائية `ar-SY-AmanyNeural`، والعراقية الرجالية `ar-IQ-BasselNeural` والنسائية `ar-IQ-RanaNeural`، والسعودية الرجالية `ar-SA-HamedNeural` والنسائية `ar-SA-ZariyahNeural`. الصوتان الفصيحان إقليميان سوريان يقرآن نصًا فصيحًا؛ لا يُدَّعى تحييد لهجي معتمد. السرعة −5%.

هذه أصوات عصبية آلية، وليست تسجيلات بشرية في استوديو أو إنتاج ElevenLabs. المصدر MP3 مضغوط بمعدل 48 كيلوبت/ثانية، 24 كيلوهرتز، أحادي القناة. تصدر الملفات بعد المعالجة بمعدل 160 كيلوبت/ثانية مع الحفاظ على معدل العينة والقناة الأصليين. رفع معدل الترميز لا يعيد التفاصيل المفقودة في المصدر، ولا تُضاف قنوات أو عينات أعلى لإيهام المستخدم بجودة جديدة.

تُستهدف جهارة −16 LUFS وذروة −1.5 dBTP قبل الضغط. عند تجاوز الذروة هامش الأمان بعد الضغط، تُعاد معالجة المصدر نفسه مرة واحدة بهامش −2.5 dBTP بدل توليد النطق مجددًا. يجب أن تكون الذروة المقاسة بعد التصدير ≤−1 dBTP والجهارة ضمن −18 إلى −14 LUFS. تُقسَّم النصوص الجديدة إلى مقاطع قصيرة، وتُتحقق حدود الكلمة الأخيرة لكل مقطع، وتُدمج بيانات MP3 دون ترميز إضافي قبل المعالجة النهائية.

في الدفعة الأولى أُصلحت ذروة الملف العراقي الرجالي الأول من مصدره المحفوظ، وكشف التفريغ الآلي نقص خاتمة الملف السعودي الرجالي الخامس؛ أُعيد إنتاج هذا الملف وحده كاملًا واجتاز إعادة الفحص. أدت هذه المراجعة إلى تقسيم النصوص الجديدة وفحص نهايات المقاطع قبل دمجها.

## الإنتاج والفحص والتفعيل

استخدم بيئة اختيارية منفصلة دون تغيير اعتماديات تطبيق الويب:

```bash
python3 -m venv /tmp/lecture-audio-venv
/tmp/lecture-audio-venv/bin/pip install -r scripts/requirements-exam-audio.txt
python3 scripts/prepare-all-subject-audio.py
/tmp/lecture-audio-venv/bin/python scripts/produce-lecture-audio.py \
  --work /tmp/lecture-audio-production --concurrency 3 --skip-enable
```

تتطلب الأدوات `ffmpeg` و`ffprobe` والصياغات الثلاث المكتملة لكل محاضرة قبل بدء الإنتاج. يستأنف المولّد الملفات التي تطابق بصمات المصدر والنص والصوت والملف، سواء وجدت إيصالات العمل القديمة أم كانت بياناتها مثبتة في الفهرس. لا تتغير إتاحة الفهرس إذا فشل تسجيل من الدفعة. يحتفظ مجلد العمل بالمصادر والمقاطع والتقارير غير المنشورة.

يتطلب فحص التفريغ التالي `manus-speech-to-text` في بيئة Manus. تُربط النتائج ببصمات MP3 ولا يُستخدم تفريغ قديم بعد تغيير الملف:

```bash
python3 scripts/verify-lecture-audio-content.py \
  --root "$PWD" --production-report /tmp/lecture-audio-production/production-report.json \
  --work /tmp/lecture-content-qa --concurrency 3
/tmp/lecture-audio-venv/bin/python scripts/produce-lecture-audio.py \
  --work /tmp/lecture-audio-production --concurrency 3 \
  --content-verification /tmp/lecture-content-qa/content-verification.json
node scripts/sync-exam-audio.mjs
node scripts/sync-exam-audio.mjs --check
```

تقارن المراجعة النص المسموع بالنص المقروء، مع فحص البداية والخاتمة، لكنها لا تشهد بهوية متحدث بشري أو بصحة لهجة لدى متحدث أصلي. يرفض المولّد تفعيل تسجيل إذا كان تحقق محتواه ناقصًا أو قديمًا. يمكن اختيار مادة باستخدام `--subject <UUID-or-slug>` دون تفعيل ملفات المواد الأخرى؛ لا تُعتبر دفعة جزئية تغطية كاملة.

## المزامنة والنشر

تتحقق المزامنة من بيانات المواد والمحاضرات والمسارات وبصمات النصوص والأصوات، ثم تنسخ الصفحة والأصول إلى `web/public/`. يتأكد GitHub Actions من تطابق بيانات المواد مع المصادر المعتمدة وتطابق النسخ المنشورة مع الأصل، ويشغّل اختبارات سلامة الإنتاج دون طلب صوت من المزوّد.

هذا إنتاج صريح قابل للاستئناف، وليس خدمة مستمرة أو جدولًا مستقبليًا. يجب دمج تحديثات `main` قبل Push دون Force Push، والتحقق من نشر الملفات فعليًا عبر HTTP وبصماتها. لا تُخفَّض الجودة أو تُستبدل التسجيلات بمقاطع صامتة أو بصوت آخر لتجاوز عطل أو قيد استضافة.
