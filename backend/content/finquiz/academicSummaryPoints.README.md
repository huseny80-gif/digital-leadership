# Reviewed academic summary points

`academicSummaryPoints.json` contains 273 editorially reviewed explanations for
the 27 current lecture editions across all five subjects. Each bullet has a
specific title, a concise explanation, and evidence from its selected PDF.

The source PDF checksum, lecture number and transcript checksum must match.
Transcript coordinates are one-based extracted-text lines, not PDF pages.
Legal explanations reference the separately page-reviewed passages in
`legalAcademicReadings.json`. Conditions, exceptions and legal qualifications
are retained. Exercise instructions, question banks, bibliography and scan
debris are excluded from the explanatory text.

The post-generation guard accepts an academic paraphrase only when the full
section, evidence quotes, file identities and coordinates exactly match this
released review, and the complete selected source context matches a verified
transcript of the same PDF. A policy label alone never authorizes new prose.
Unreviewed source editions continue to use complete source excerpts only.

The sixth cybersecurity lecture is a private upload. Its reviewed transcript
does not replace authorization or storage verification: its points are applied
only after the caller verifies the actual uploaded bytes and checksum.

The same points serve the summary library, examination review, printing,
concept map and academic narration. Full lecture readings and PDFs remain
available independently. Old quiz editions, answer keys, attempts and saved
summary snapshots are not rewritten. Current bookmarks receive the reviewed
study presentation only for the exact same source edition.
