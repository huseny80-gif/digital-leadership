# جولة المنصة المصوّرة (Platform Walkthrough)

أداة تدخل المنصة كما يفعل المستخدم، بمؤشر ماوس ظاهر يتحرك بانسيابية وينقر ويمرّر، وتلتقط لقطات Full HD لكل صفحة وتبويب، ثم تبني منها:

| الملف | الوصف |
|---|---|
| `out/shots/*.png` | لقطات 1920×1080 (ولقطة «الصفحة كاملة» `*-full.png` للصفحات الطويلة) |
| `out/REPORT.md` و`out/manifest.json` | سجل التوثيق: كل لقطة مع مسارها وعنوانها وشرح ما تُظهره ومواضع النقرات وأخطاء وحدة التحكم |
| `out/deck/index.html` | عرض تفاعلي يعمل دون إنترنت: `Space` تشغيل/إيقاف، `←`/`→` تنقل، `F` ملء الشاشة |
| `out/walkthrough.mp4` | العرض نفسه فيديو Full HD بانتقالات سلسة وتصميم داكن بلمسات زجاجية (Glassmorphism) |
| `out/session.mp4` | تسجيل الجلسة الحقيقي بحركة المؤشر كما نُفّذت |
| `out/walkthrough-full.mp4` | العرض ثم الجلسة في ملف واحد |

## المتطلبات

- Node.js 22 و`ffmpeg` في المسار.
- `cd tools/platform-walkthrough && npm install && npx playwright install chromium`
  (إن كانت Playwright مثبّتة في `web/` أو عالمياً فستُستخدم تلقائياً).

## التشغيل

```bash
# 1) الدخول برابط تدريب (بدون حساب): الرابط الذي يُنشئه المدير من /admin/training-access
BASE_URL=https://موقعك JOIN_TOKEN=رمز-الرابط npm run all

# 2) أو بجلسة مسجّلة (Google أو مدير): احفظها مرة واحدة ثم أعد استعمالها
npx playwright codegen --save-storage=auth.json https://موقعك/login   # سجّل الدخول يدوياً ثم أغلق النافذة
BASE_URL=https://موقعك STORAGE_STATE=auth.json INCLUDE_ADMIN=1 npm run all
```

`npm run capture` يلتقط فقط، و`npm run compose` يبني العرض والفيديو من آخر التقاط. رمز الرابط لا يُكتب في أي ملف ناتج (يُستبدل بـ `<token>`).

## الإعدادات (متغيرات بيئة)

| المتغير | الافتراضي | المعنى |
|---|---|---|
| `BASE_URL` | `http://localhost:3000` | عنوان المنصة |
| `JOIN_TOKEN` / `JOIN_URL` | — | رمز رابط التدريب أو الرابط كاملاً |
| `STORAGE_STATE` | — | ملف جلسة Playwright لحساب مسجّل |
| `INCLUDE_ADMIN` | `0` | زيارة صفحات الإدارة (يتطلب جلسة مدير) |
| `GUEST_NAME` | زائر العرض التوضيحي | الاسم الذي يُكتب في نموذج الدخول |
| `SPEED` | `1` | سرعة الحركة (`0.5` أبطأ بمرتين، `2` أسرع بمرتين) |
| `MAX_SUBJECTS` | `5` | عدد المواد المزورة |
| `SCROLL_STOPS` | `2` | عدد لقطات التمرير في الصفحة الطويلة |
| `MAX_TABS` | `5` | أقصى عدد تبويبات تُنقر في الصفحة |
| `LECTURES_PER_SUBJECT` | `1` | محاضرات تُزار لكل مادة |
| `FEATURED_LECTURES` | — | تعابير نمطية لمحاضرات تُزار دائماً، مثل `الرابعة مخاطر,الخامسة مخاطر` |
| `EXTRA_PAGES` / `ADMIN_PAGES` | قوائم جاهزة | صفحات إضافية مفصولة بفواصل |
| `WARMUP` | `1` | زيارة الصفحات مرة خارج التسجيل لتجنب انتظار البدء البارد |
| `WIDTH`, `HEIGHT` | `1920`, `1080` | الدقة |
| `OUT_DIR` | `./out` | مجلد الناتج |
| `NO_VIDEO` | `0` | `1` يكتب العرض التفاعلي فقط دون فيديو |

## كيف تعمل

1. **الدخول:** لقطة لصفحة الدخول العامة، ثم نموذج رابط التدريب (يكتب الاسم حرفاً حرفاً وينقر «Join»)، أو جلسة محفوظة.
2. **نافذة الترحيب:** تُلتقط مرة واحدة ثم تُغلق بنقرة «تصفح المنصة» كي لا تحجب المحتوى.
3. **التنقل:** من لوحة التحكم إلى المواد، ولكل مادة: نظرة عامة وPDF والملخصات والخرائط الذهنية والاختبارات والمادة الامتحانية والتكليفات والمراجع وعيّنة من المحاضرات، ثم العروض المشتركة (المحاضرات/الملخصات/الواجبات/الاختبارات/الملفات) والتقارير. تنقر الأداة الرابط الظاهر على الشاشة إن وُجد وإلا تفتح العنوان.
4. **الحركة:** مسار منحنٍ بتسارع وتباطؤ، توقف قصير فوق العنصر ثم نقرة بتموّج (ripple)، وتمرير بعجلة الفأرة على خطوات صغيرة.
5. **التركيب:** يعيد العرض تمثيل حركة المؤشر على كل لقطة (نفس موضع النقرة)، ويُسجَّل تشغيله فيديو.

## حدود معروفة

- الصفحات التي تحتاج صلاحية أعلى من جلسة الزائر تُسجَّل في التقرير بملاحظة `redirected to …` ولا تفشل الجولة.
- تسجيل Google لا يُؤتمت (حماية من المزوّد)، لذلك تُستعمل جلسة محفوظة يدوياً أو رابط تدريب.
- الجولة على خادم تطوير Next.js بطيئة في أول زيارة؛ مرحلة `WARMUP` تعالج ذلك.
