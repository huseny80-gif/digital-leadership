# صيغ ملفات الإدخال

ثلاثة ملفات JSON تكتبها بيدك قبل تشغيل `register_lecture.mjs`. كل اقتباس فيها (`evidence` أو `text` في القراءة) يجب أن يكون **نصاً حرفياً** من `transcript.txt`؛ يتجاهل الفحص التشكيل والمسافات الزائدة والأقواس `()` فقط.

## summary.json — الملخص الأكاديمي
```json
{
  "overview": "جملة أو جملتان تلخصان موضوع المحاضرة كلها.",
  "sections": [
    {
      "heading": "عنوان القسم",
      "points": [
        {
          "term": "المصطلح أو عنوان النقطة",
          "text": "شرح النقطة بصياغتك، مختصراً ودقيقاً.",
          "evidence": ["مقطع حرفي من المحاضرة يدعم النقطة", "مقطع ثانٍ إن لزم"]
        }
      ]
    }
  ]
}
```
- كل نقطة لها دليل واحد على الأقل، والنص (`text`) لا يضيف معلومة غير مذكورة في المحاضرة.
- في المحاضرة السابعة القانونية: 6 أقسام و29 نقطة. العدد تابع لمحتوى المحاضرة، لا هدف بحد ذاته.
- من هذا الملف تُبنى تلقائياً الخريطة الذهنية وخريطة المفاهيم ومخطط التسلسل وتبويب الملخصات والبودكاست.

## cases.json — الحالات التحليلية (مصفوفة)
```json
[
  {
    "id": "legal7-legal-tender",
    "prompt": "موقف عملي قصير ينتهي بسؤال: أي تكييف/قرار/أولوية ينسجم مع المحاضرة؟",
    "skill": "decision",
    "criterion": "المعيار الذي يُحكم به على الإجابة، بعبارة قصيرة",
    "evidence": ["مقطع حرفي يحدد المعيار"],
    "options": [
      { "text": "الخيار الصحيح", "isCorrect": true,  "rationale": "لماذا هو صحيح", "evidence": ["مقطع حرفي"] },
      { "text": "مشتت 1",        "isCorrect": false, "rationale": "لماذا هو خاطئ", "evidence": ["مقطع حرفي يبين الخطأ"] },
      { "text": "مشتت 2",        "isCorrect": false, "rationale": "...", "evidence": ["..."] },
      { "text": "مشتت 3",        "isCorrect": false, "rationale": "...", "evidence": ["..."] }
    ]
  }
]
```
- `skill` واحدة من: `decision` و`diagnosis` و`prioritization`؛ نوّع بينها (في المحاضرة السابعة: 2 قرار، 4 تشخيص، 2 أولويات).
- معرّف الحالة (`id`) فريد في كل الملف؛ ابدأه باسم المادة ورقم المحاضرة.
- خيار صحيح واحد بالضبط، وثلاثة مشتتات على الأقل يمكن دحض كل منها بمقطع من المحاضرة. لا يكون المشتت صحيحاً جزئياً.
- لا تضع `sha256` في الحالات؛ السكربت يضيفه من بصمة الملف.
- بعد كتابتها شغّل وكيل `exam-reviewer` (قراءة فقط) على الحالات قبل فتح PR.

## reading.json — القراءة القانونية (مادة legal-regulatory فقط)
```json
{
  "pageCount": 17,
  "topics": [
    {
      "title": "عنوان الموضوع",
      "passages": [
        { "page": 2, "text": "مقطع حرفي من المحاضرة، بين 25 و1500 حرف." }
      ]
    }
  ]
}
```
- أربعة مواضيع على الأقل، و`pageCount` هو عدد صفحات ملف PDF الحقيقي.
- ممنوع في نص المقطع: كلمات لاتينية (مثل Bitcoin)، والرمز `|`، والروابط، وتكرار مقطع. اختر مقاطع بالعربية الخالصة.
- `page` هو رقم الصفحة الفعلي في الملف الذي يظهر فيه المقطع. لا تقدّره من ترتيب النص: في المحاضرة السابعة كان رقما صفحتين من نحو عشرين مقتبساً خطأين حين قُدّرا، وصححهما فتح صور الصفحات. افتح صورة كل صفحة مستشهَد بها وتأكد من وجود المقطع فيها.
- القراءات تُعرض للمتدرب مع رقم الصفحة، فرقم خاطئ معلومة مضللة.
